# Beautiful UI

The chat composer, sidebar, streaming text, loading state, thinking state, and tool chips are adapted from the public Beautiful UI component examples at https://www.beautifului.dev/ and its harness at https://www.beautifului.dev/harness.

Source retrieved September 28, 2026. The supplied component code is available under the license at https://www.beautifului.dev/license. Adaptations replace gallery storyboards with application state, use Vitamin-C content and Lucide icons, add accessibility and reduced motion behavior, and connect chat presentation to a local mock event stream.

# shadcn/ui and Streamdown

The conversation uses the official `@shadcn/react` MessageScroller primitive (version 0.3.1), with application-specific Quiet UI wrappers. Source: https://github.com/shadcn-ui/ui, MIT license, Copyright (c) 2023 shadcn. Its full license is distributed in the installed package at `node_modules/@shadcn/react/LICENSE.md`.

Streaming Markdown uses Streamdown (version 2.7.0), https://github.com/vercel/streamdown, Copyright 2023 Vercel, Inc., Apache License 2.0. Its license is distributed in the installed package at `node_modules/streamdown/LICENSE`. No optional code, math, or diagram plugins are installed.
